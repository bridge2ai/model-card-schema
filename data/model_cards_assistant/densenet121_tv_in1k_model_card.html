Overview

DenseNet-121 (Huang et al., CVPR 2017) concatenates earlier feature maps within each dense block.
This card covers the public ImageNet-1k checkpoint `timm/densenet121.tv_in1k`.
Its upstream card identifies original torchvision weights; torchvision records that these were
ported from LuaTorch. The timm distribution provides image classification and feature extraction.
The relationship between this public checkpoint and any CM4AI-specific trained model has not
been established by the sources cited here.

Documentation

## Model Architecture
- Backbone: DenseNet-121 with four dense blocks
- Growth rate: 32 (feature maps added per layer)
- Total parameters: ~8.0M
- Compute: 2.9 GMACs at 224x224
- Activations: 6.9M
- Input resolution: 224 x 224

Model Parameters

Architecture

DenseNet-121 architecture with 4 dense blocks (each with growth rate 32) interleaved with
transition layers (1x1 conv + 2x2 average pool). Total ~8.0M parameters, ~2.9 GMACs at 224x224.
Final 1000-way classifier head trained on ImageNet-1k.

Input format

RGB images; timm config specifies bicubic resize, center crop to 224x224, and ImageNet normalization

Datasets

ImageNet-1k (ILSVRC2012)

The ILSVRC2012 organizers describe approximately 1.2 million training images and 50,000 labeled validation images across 1000 object categories. Training and validation are distinct benchmark splits; the listed accuracy results use validation, not the hidden-label challenge test set. The dataset is obtained separately from the weights. Source: https://image-net.org/challenges/LSVRC/2012/index.php

bias_input: The training label space is restricted to ImageNet-1k object categories. Aggregate ImageNet accuracy does not establish coverage of a deployment population or microscopy domain; an application-specific dataset audit and evaluation are still needed.

Training procedure

Supervised ImageNet-1k classification. Torchvision identifies the supplied weights as a LuaTorch port (https://github.com/pytorch/vision/pull/116); timm redistributes them. A current torchvision reference training script is not evidence of this checkpoint's run.

methodology
The original paper's ImageNet recipe uses SGD with Nesterov momentum 0.9, weight decay
1e-4, batch size 256 and 90 epochs. Initial learning rate 0.1 is reduced tenfold at
epochs 30 and 60 (https://arxiv.org/html/1608.06993v5#S4.SS2).
These are paper-level settings, not a recovered run manifest for the Hub artifact.
Exact seed, software versions, checkpoint selection and run-specific configuration
remain unverified; numeric hyperparameter fields are therefore left unset.

Evaluation procedure

description
Accuracy values are quoted from torchvision's DenseNet121_Weights.IMAGENET1K_V1 metadata,
not measured by this card's authors: https://docs.pytorch.org/vision/main/models/generated/torchvision.models.densenet121.html
Torchvision documents bilinear resize to a short edge of 256, then a 224x224 center crop
and ImageNet normalization. Top-1/top-5 accuracy is the percentage of validation examples
whose target is among the one/five highest-ranked classes.
The timm Hub config instead specifies bicubic interpolation. The quoted torchvision
scores must not be treated as a fresh measurement of the pinned Hub model using timm's
default transforms. The timm-reported 8.0M parameters and 2.9 GMACs are architecture
descriptors, not accuracy measurements or training compute estimates.
benchmarks
ILSVRC2012 / ImageNet-1k classification, validation split (50,000 images; 1000 classes)

Considerations

Intended users

  • ML researchers and engineers using DenseNet-121 as a baseline for image-classification benchmarks, a feature backbone for transfer learning, or a building block in detection and segmentation pipelines.

Use cases

  • ImageNet-1k image classification baseline
  • Transfer learning backbone for downstream computer-vision tasks
  • Feature extraction (forward_features) for use in detection / segmentation
  • Educational reference implementation of densely-connected architectures

Limitations

  • Trained on ImageNet-1k only; out-of-distribution performance on non-ImageNet domains (medical imaging, satellite imagery, microscopy) is unknown without further fine-tuning.
  • The reviewed model card and torchvision metadata provide aggregate accuracy. Per-class, demographic, microscopy and CM4AI-specific results are not established by those sources.
  • Confidence intervals, repeated-run estimates, calibration results, original training hardware, wall time and energy consumption are not established by the reviewed sources. No confidence bounds or compute estimates are inferred from rounded aggregate scores.

Tradeoffs

  • Dense connectivity reuses feature maps, but parameter count alone does not predict deployment latency or memory consumption. Benchmark the implementation on target hardware.
  • For downstream model selection, compare aggregate accuracy with per-class recall and worst-subgroup error on relevant, adequately sized evaluation slices. A gain in average accuracy can coexist with worse performance for a particular class or subgroup. Set acceptance criteria according to the consequences of those errors and report sample sizes and uncertainty. This is a recommendation by this card's maintainers; no observed disparity or quantified accuracy-versus-fairness tradeoff is claimed here.

Ethical considerations

  • Deployment outside the documented benchmark
    Mitigation: Evaluate error rates and calibration on representative target data and relevant subgroups before relying on predictions. Review data rights, privacy and category suitability for the intended application. These are recommendations by this card's maintainers, not a claim that the original developers performed those audits.

Out-of-scope uses

  • Face recognition / identification
  • Demographic classification (age, gender, ethnicity)
  • Surveillance applications
  • Clinical / medical diagnosis without dedicated retraining and regulatory clearance

Bias Disclosure

bias_model: The cited aggregate benchmark does not establish equitable performance across populations or suitability for biomedical images. This card makes no claim that a fairness audit has or has not been performed elsewhere; deployment-specific evidence is needed.
bias_output: Predictions rank the fixed ImageNet-1k classes. Softmax scores are not evidence of calibrated confidence, and the classifier has no explicit unknown-class output. Calibration and out-of-distribution behavior require evaluation on the intended application.

Usage Documentation

installation_instructions
Install a compatible PyTorch/torchvision pair using https://pytorch.org/get-started/locally/,
then install `timm`, `huggingface_hub`, `safetensors` and `Pillow` in that environment.
These instructions describe inference dependencies, not the original LuaTorch training
environment. An exact tested dependency lock has not been established for this card.
training_configuration
The original authors provide this ImageNet training example in their repository README:
`th main.lua -netType densenet -dataset imagenet -data [dataFolder] -batchSize 256 -nEpochs 90 -depth 121 -growthRate 32 -nGPU 4 -nThreads 16 -optMemory 3`
Source: https://github.com/liuzhuang13/DenseNet#usage
This is a documented reproduction example. In particular, its GPU count and later memory
optimization options do not establish the hardware or exact command used for the ported weights.
inference_configuration
The example below loads a fixed Hub revision on CPU and preprocesses a local RGB image
using that model's timm configuration. It returns five zero-based ImageNet class indices
and softmax scores. Match indices to the ImageNet-1k category mapping before displaying labels.
The weights download on first use. This example has not been executed with model weights
during this documentation review, and its scores are not an evaluation result.

    code
    from PIL import Image
import torch
import timm

revision = "f0d0f2698a02cb133b09d48396db6e1e46fe9f3b"
model = timm.create_model(
    f"hf-hub:timm/densenet121.tv_in1k@{revision}",
    pretrained=True,
).eval()
data_config = timm.data.resolve_model_data_config(model)
transform = timm.data.create_transform(**data_config, is_training=False)
image = Image.open("image.jpg").convert("RGB")
with torch.inference_mode():
    logits = model(transform(image).unsqueeze(0))
    scores, class_indices = logits.softmax(dim=-1).topk(5, dim=-1)
print(class_indices[0].tolist(), scores[0].tolist())
