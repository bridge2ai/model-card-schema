Overview

This card describes the public SaProtHub/Model-Subcellular_Localization-650M adapter,
with base model westlake-repl/SaProt_650M_AF2. It does not establish that this checkpoint
is a CM4AI-trained model or that it has been validated on CM4AI data.

The upstream model README reports 85.75% test accuracy on the linked SaProtHub DeepLoc
dataset. This is an author-reported result, not an independently reproduced measurement.
The dataset describes a ten-class, single-label task derived from the original 2017
DeepLoc dataset, using AlphaFold2 structure-aware sequences. It is not identified as
DeepLoc 2.0. The audited dataset snapshot contains validation/test sequence overlap;
see the evaluation procedure for the finding and its provenance limits.

Model Parameters

Architecture

SaProt_650M_AF2 is the approximately 650M-parameter, ESM-style transformer base
using a structure-aware amino-acid/3Di vocabulary. The adapter config names that
base and LoRA SEQ_CLS adaptation, with rank 16, alpha 32 and dropout 0, targeting
query, key, value, intermediate.dense and output.dense. The classifier is saved
with the adapter. The upstream classification implementation uses an ESM sequence
classification model producing ten logits; the adapter weights were not loaded
or independently inspected during this documentation revision.

Input format

Structure-aware (SA) sequence: each amino-acid letter is paired with a Foldseek 3Di structural token; # denotes a masked structural token.

type
string
encoding
One uppercase amino-acid letter followed by one lowercase structural letter or # per residue; for example M#Ev.
length_handling
The current upstream classification dataset implementation defaults to 1024 residue/SA tokens and truncates longer inputs. The trained adapter's exact preprocessing limit is not recorded in its README.

Output format

Ten class logits per protein; argmax produces a single integer label 0-9. ColabSaprot exports predicted_label and softmax predicted_probabilities.

logits_shape
[batch_size, 10]
label_mapping
0=Nucleus; 1=Cytoplasm; 2=Extracellular; 3=Mitochondrion; 4=Cell.membrane; 5=Endoplasmic.reticulum; 6=Plastid; 7=Golgi.apparatus; 8=Lysosome/Vacuole; 9=Peroxisome
interpretation
A single-label prediction; softmax values are not documented as calibrated probabilities.

Datasets

SaProtHub DeepLoc subcellular localization dataset

The publisher links the original 2017 DeepLoc publication. Its README says proteins lacking AlphaFold2 structures were excluded and describes a split based on 70% structure similarity using ProteinShake. CSV revision 78096a0eff765cf8988323ca3c21c0f19ca1ae79 contains 13,150 rows with columns protein, label and stage: 10,414 train, 1,368 valid and 1,368 test. These counts were checked directly on the published CSV. The stage column defines subsets within one file; the Hugging Face dataset config is named dataset. The model's reported score is not explicitly bound to this CSV revision. An exact string audit finds 232 unique SA sequences shared by valid and test, and one AA-only sequence shared by train and test. This needs investigation against the original scored split manifest before asserting evaluation independence.

Sensitive data: The inspected CSV has protein, label and stage columns; it has no individual-level demographic or clinical metadata columns.
bias_input: The publisher's AF2-availability filter limits coverage to proteins with available structures. Observed training class counts in label order 0-9 are [2641, 1913, 1498, 1323, 979, 745, 633, 282, 268, 132]. Species and protein-family identifiers are not present in the inspected CSV, so their distributions cannot be established from this artifact alone.

Evaluation procedure

description
The model README reports 85.75% accuracy on the linked dataset's test set. For a
single-label task, accuracy is the fraction of predictions whose highest-scoring
class matches the reference label. The current upstream classifier uses accuracy
and cross-entropy; predictions and a run-level evaluation report were not supplied
with the model repository, so this result has not been reproduced here.

The inspected dataset revision has 1,368 rows marked test. Its valid and test
subsets share 232 distinct, identical SA strings. Comparing only their amino-acid
components gives 233 valid/test overlaps and one train/test overlap; train/test
SA-string overlap is zero. Counts are intersections of unique strings, not row
counts. This audit concerns the pinned mirror and does not prove that the original
scored run used these exact splits. Original split IDs, run/checkpoint provenance
and per-example predictions are required to assess possible contamination.
benchmarks
Ten-class single-label subcellular localization on SaProtHub/Dataset-Subcellular_Localization-DeepLoc; the publisher cites the original 2017 DeepLoc dataset.

Considerations

Intended users

  • Researchers studying protein localization and evaluating structure-aware protein classifiers.

Use cases

  • Research screening of protein subcellular localization from structure-aware inputs, followed by independent validation.
  • Evaluation of this public adapter against a documented, independently checked split and its fixed ten-class label mapping.

Limitations

  • The checkpoint is single-label: it returns one of ten categories and cannot represent multiple simultaneous localizations through its documented label output.
  • The model is trained on SA inputs. Generic SaProt software supports amino-acid-only modes, but the reported score does not establish this adapter's performance without structural information; the current ColabSaprot workflow enforces structure input for adapters marked SA.
  • Exact preprocessing, long-protein truncation settings and structural-confidence handling for the scored run are not bound to this artifact. Current upstream defaults should not be presented as the historical run's settings.
  • The score lacks a bound evaluation manifest, per-class metrics, calibration, confidence intervals and repeated-seed results. The observed current-mirror split overlap must be resolved before treating validation and test data as independent.
  • Validation on CM4AI data, species-specific generalization and performance on underrepresented compartments remain unestablished by the inspected artifacts.

Tradeoffs

  • LoRA permits distribution of the adapter and classifier, but inference still requires the 650M base model and structure-aware preprocessing. No measured compute or latency comparison is supplied for this checkpoint.
  • Curator recommendation: when comparing or selecting localization models, assess per-compartment recall and macro-F1 alongside aggregate accuracy. The observed class imbalance means frequent compartments contribute more to overall accuracy; prioritizing rare-compartment recall may produce a different model choice. This is a metric-selection tradeoff, not evidence that this adapter under-predicts rare compartments.

Ethical considerations

  • Incorrect localization used as biological evidence
    Mitigation: Curator recommendation: treat predictions as research hypotheses and validate with appropriate experimental localization evidence before downstream biological decisions.

Out-of-scope uses

  • Curator-defined scope: standalone clinical diagnosis or therapeutic decisions without task-specific clinical validation.
  • Claims of CM4AI-specific performance, multi-label localization or calibrated confidence without corresponding validation data.

Bias Disclosure

bias_model: Observed documentation and dataset limitations: the AF2-availability filter and uneven training label counts can affect the populations and compartments represented. Species and family composition, and their effects on model performance, are not established by the inspected CSV and model README.
bias_output: Per-class output bias has not been measured in the supplied artifacts. The training label imbalance alone does not establish under-prediction of any compartment; per-example predictions and class-level precision/recall are needed to assess it.

training_configuration
The checkpoint README reports AdamW with learning rate 0.0005, betas (0.9, 0.98),
weight decay 0.01, batch size 64, 100 epochs and 16-mixed precision. Use rank 16,
alpha 32 and dropout 0 for its documented LoRA configuration. This is a partial

environment lockfile, preprocessing settings, split manifest and checkpoint-selection

inference_configuration
In ColabSaprot v2 choose the existing-model prediction workflow, then Protein property
prediction. Select Protein-level Classification, set Number of categories to 10,
choose Shared by peers on SaprotHub, and enter
SaProtHub/Model-Subcellular_Localization-650M. For this SA-trained adapter, select
protein structure and supply a PDB/CIF file with the intended chain. The notebook
converts structures to the SA representation and exports a prediction CSV.

Decode predicted_label using the exact 0-9 mapping in output_format_map. The notebook's
predicted_probabilities column contains softmax scores; calibration and abstention
thresholds are not established for this checkpoint. Its UI loads repository defaults;
record the resolved model, base and software revisions for any new analysis. A pinned
notebook alone does not pin its remote model downloads or installation dependencies.

    import csv
import sys

labels = [
    "Nucleus", "Cytoplasm", "Extracellular", "Mitochondrion",
    "Cell.membrane", "Endoplasmic.reticulum", "Plastid",
    "Golgi.apparatus", "Lysosome/Vacuole", "Peroxisome",
]
# Run: python decode_labels.py path/to/colabsaprot_output.csv
with open(sys.argv[1], newline="") as handle:
    reader = csv.DictReader(handle)
    if "predicted_label" not in (reader.fieldnames or []):
        raise ValueError("Expected ColabSaprot's predicted_label column")
    for row_number, row in enumerate(reader, start=1):
        label = int(row["predicted_label"])
        if not 0 <= label < len(labels):
            raise ValueError(f"Invalid class label in row {row_number}: {label}")
        print(row_number, label, labels[label], sep="\t")
